Private AI Writer

How it works

Architecture

An Android client connects to an authenticated Express API over the local network. The backend keeps a Markdown library and revision history and calls the local llama.cpp server.

Edit safety

The assistant reads sections, asks structured questions, and proposes targeted patches. A patch for a stale revision is rejected. Applied changes have a diff and an undo action in history.

Progress and testing

Tool and edit progress streams to the app, and approvals can resume. Deterministic tests cover patching, cancellation, stale revisions, and undo.
