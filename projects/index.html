Personal R&D prototype

TypeScript · Node.js · Vitest

Matrix 2.0

An AI narrative engine built on a strict split: the engine decides what is true, and the language model only decides how it is described. Actions are typed, resolution is deterministic, and every outcome is applied as a state patch with an event log. The model never writes game state.

Before a model is called, a context compiler assembles a bounded packet from the current state instead of forwarding a transcript. A provider contract keeps that boundary narrow: system text plus packet in, plain narration out. A batch harness replays cases through the same pipeline and records scorecards, latency and prompt size, alongside contract tests and end-to-end pipeline tests.

  • Deterministic state
  • Context compilation
  • LLM contracts
  • Evaluation
  • Vitest

Personal R&D prototype, not a shipped product, and no source repository is published. Memory summarisers, retrieval fallback and tool calling appear in the design notes only and are not implemented.

Working prototype

Node.js · Local JSON · Agent CLI

Systems Map

A local tool where a person and an AI coding agent maintain the same structured model of a game's concepts and the relationships between them. Ideas, accepted design and verified current behaviour are separate states, so the map can hold a discussion without pretending a proposal already exists in the game.

The agent works through a small CLI rather than free-form file edits: reads return a revision token, writes carrying a stale token are rejected instead of overwriting newer work, and batches of up to one hundred operations commit all-or-nothing. Data serializes deterministically so text diffs stay readable, and the graph lays itself out from the hierarchy with no stored coordinates.

  • Node.js
  • Structured agent CLI
  • Revision-safe writes
  • Atomic batches
  • Local-first

Standalone tool, not a Godot plugin: it does not read scenes, connect to an engine or sync automatically. Screenshots show the working prototype using an illustrative example map built from the Apartment Panic concept - not an approved game design.
